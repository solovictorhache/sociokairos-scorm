SOCIOKAIROS EDU – Research Suite para Moodle (Versión fusionada 2026)
======================================================================

Autor: Dr. Víctor Hugo Pérez Gallo
Obra: SOCIOKAIROS_EDU_SCORM
Fecha de preparación para SafeCreative: 2026-08-17

Descripción
-----------
Este paquete contiene el plugin SCORM/LTI de SOCIOKAIROS para Moodle. Integra
el motor heurístico SOCIOKAIROS (validación pedagógica del problema, detección
de variables, geolocalización mundial de fuentes de datos, alertas metodológicas,
tradiciones sociológicas, mapa lógico, diseños sugeridos y visualización SVG) en
entornos de enseñanza virtual, permitiendo la reformulación de problemas
científicos, la operacionalización de variables y el seguimiento de la
actividad del estudiantado mediante SCORM.

Contenido
---------
- Código fuente HTML y JavaScript necesario para el funcionamiento (sin
  dependencias externas: funciona sin conexión a Internet).
- imsmanifest.xml: manifiesto SCORM 1.2 del paquete.
- logo.png: logotipo oficial de SOCIOKAIROS.

Uso en SafeCreative
-------------------
Este ZIP puede subirse directamente a SafeCreative como fichero principal
de la obra "SOCIOKAIROS EDU – Research Suite para Moodle (Versión fusionada 2026)".
